# SPY / SWAP multiplayer visual feedback

- SPY now sends a small shared interaction event identifying the actor and target.
- The target sees a cinematic "PLAYER SPIED ON YOU" announcement.
- SWAP sends the same type of shared event and the affected target sees "PLAYER SWAPPED WITH YOU".
- The alert uses the acting player's selected color and zodiac identity.
- Bot SPY and SWAP actions also generate the same visual feedback.
- The actual private card reveal remains private; this event only announces WHO acted on you.
